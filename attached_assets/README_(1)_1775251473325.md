# Football Prediction & Betting Analytics Platform

A high-performance, full-stack application for football match prediction, betting portfolio management, and real-time performance analytics. The platform combines traditional statistical models (Poisson) with modern Machine Learning (Random Forest) and Generative AI (Google Gemini) to provide actionable betting insights.

## 🚀 Core Features

### 1. Advanced Prediction Engine
- **Hybrid Model Architecture**: Combines a TypeScript-based **Random Forest Classifier** (`ml-random-forest`) with a classical **Poisson Distribution** model.
- **Real-Time xG Integration**: Uses Expected Goals (xG) data for both teams to drive more accurate scoreline and outcome probabilities.
- **Monte Carlo Simulations**: Runs 10,000+ simulations per match to generate a full probability distribution of potential scores.
- **Automated Retraining**: The ML model automatically retrains itself when performance metrics (like Brier Score or AUC-ROC) fall below defined thresholds.

### 2. AI-Driven Insights (Gemini Integration)
- **Bayesian Reasoning**: Gemini AI processes structured match data and unstructured context to provide a "reasoning layer" over raw probabilities.
- **Risk Assessment**: Generates natural language warnings and risk profiles for every prediction.
- **Market Recommendations**: Suggests specific betting markets (1X2, Over/Under, BTTS) based on detected value edges.

### 3. Portfolio & Risk Management
- **Active Bet Tracking**: Real-time monitoring of placed bets with live status updates.
- **Kelly Criterion Integration**: Suggests optimal stake sizes based on the calculated "edge" over market odds.
- **Parlay Builder**: Advanced logic for constructing multi-bet parlays with correlated outcome protection.
- **Performance Dashboard**: Comprehensive analytics including ROI, Win Rate, Brier Score, and AUC-ROC.

### 4. Data Pipeline & Backtesting
- **Automated ETL**: Modular pipeline for ingesting, cleaning, and vectorizing historical match data.
- **Historical Simulation**: Backtest strategies against years of historical data to verify model alpha.
- **Live Telemetry**: Sub-second updates for live match events and market odds shifts.

## 🛠 Technical Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion (Animations), Recharts (Data Viz).
- **Backend**: Express.js (Node.js), TypeScript.
- **Machine Learning**: `ml-random-forest` (TypeScript), Python (Historical Data Processing).
- **AI**: Google Gemini Pro (`@google/genai`).
- **Data Sources**: Football-Data.org API, CSV-based historical archives.

## 📈 Performance Metrics

The platform tracks several key performance indicators (KPIs) to ensure model reliability:

| Metric | Description | Target |
| :--- | :--- | :--- |
| **ROI** | Return on Investment across all settled bets. | > 5% |
| **Brier Score** | Measures the accuracy of probabilistic predictions (lower is better). | < 0.20 |
| **AUC-ROC** | Measures the model's ability to discriminate between outcomes. | > 0.70 |
| **Win Rate** | Percentage of successful predictions. | > 55% |

## 🛡 Risk Management

- **Unit Size Control**: Strict enforcement of maximum stake percentages to prevent ruin.
- **Correlation Guard**: Detects and warns against highly correlated bets in a single portfolio.
- **Model Drift Detection**: Continuous monitoring of prediction accuracy to trigger retraining.

## 🚦 Getting Started

1. **Environment Setup**:
   - Copy `.env.example` to `.env`.
   - Add your `FOOTBALL_DATA_API_KEY` and `GEMINI_API_KEY`.

2. **Installation**:
   ```bash
   npm install
   ```

3. **Development**:
   ```bash
   npm run dev
   ```

4. **Initial Training**:
   The server will automatically train the initial ML model on first startup using the historical data in `data/enriched_historical.csv`.
